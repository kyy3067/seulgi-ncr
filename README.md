# 슬기로운 NCR (PWA)

델리 수도권(NCR) 여행·생활 도우미 앱. 환율 변환, 맛집·명소(사진·리뷰·연락처·지도), 추천 특산물, 팁 기록 기능을 담은 설치형 웹앱(PWA)입니다.

## 폴더 구성
```
index.html              앱 본체
manifest.webmanifest    앱 정보(이름/아이콘/색상)
sw.js                   서비스워커(오프라인 + 자동 최신화)
icons/icon-192.png
icons/icon-512.png
```

## GitHub Pages로 배포하기
1. 새 저장소(repo)를 만들고 위 파일을 **저장소 루트**에 그대로 올립니다.
2. Settings → Pages → Source: `main` 브랜치 / `/ (root)` 선택 후 저장.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생성됩니다.

> ⚠️ PWA 설치·서비스워커는 **HTTPS에서만** 동작합니다. GitHub Pages는 기본 HTTPS라 그대로 됩니다.

## 폰에 설치
- 안드로이드 Chrome에서 위 주소 접속 → 메뉴(⋮) → **"앱 설치"** 또는 **"홈 화면에 추가"**.
- 아이폰 Safari → 공유 → **"홈 화면에 추가"**.
- 홈 화면 아이콘으로 열면 주소창 없는 전체화면 앱처럼 실행됩니다.

## 수정사항 반영 (핵심)
- 코드를 고쳐 GitHub에 **push** → Pages가 자동 갱신 → **앱을 다시 열면 최신 버전**이 나옵니다.
- HTML은 network-first라 온라인이면 항상 최신본을 불러옵니다. 재설치 불필요.
- (드물게 캐시가 남으면 앱을 완전히 닫았다 다시 열거나, `sw.js`의 `VERSION` 값을 `ncr-v2`처럼 올려 push 하세요.)

## 데이터 저장
- 맛집·특산물·팁·사진·환율은 **기기 내 IndexedDB**에 저장됩니다(서버 전송 없음).
- 같은 기기·같은 브라우저에서만 보입니다. 앱 데이터를 지우면 함께 삭제됩니다.

## 진짜 .apk 파일이 필요하면
이 PWA를 배포한 뒤 [PWABuilder](https://www.pwabuilder.com)에 주소를 넣으면 서명된 Android 패키지(APK/AAB)를 받을 수 있습니다.
